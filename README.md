### Deep Packet Inspection and Analyzer
*C++17 · Networking · Multithreading — August 2026*

Built a Deep Packet Inspection engine to parse PCAP network captures across Ethernet, IPv4, TCP/UDP layers and track connections using 5-tuples. Implemented TLS SNI and HTTP Host extraction to identify application/domain traffic and classify services such as YouTube, Facebook, and Google. Developed configurable IP, application, and domain-based traffic filtering, with flow-level blocking and forwarded/dropped packet tracking. Designed a multi-threaded processing pipeline using load balancers, fast-path workers, consistent hashing, and thread-safe producer-consumer queues for parallel packet processing.

| Language | C++17 |
| Domain | Networking / Packet Analysis |
| Concurrency | Multithreading, Producer-Consumer Queues, Consistent Hashing |
| Protocols | Ethernet, IPv4, TCP/UDP, TLS SNI, HTTP |

### SimpleKafka — Kafka-like Distributed Messaging System
*Java · Maven · ZooKeeper · Distributed Systems — August 2026*

Built a Kafka-like distributed messaging system from scratch, implementing core components including brokers, storage, client libraries, and producer/consumer APIs. Implemented topic partitioning and replication across multiple broker instances with leader/follower mechanics and broker coordination through ZooKeeper. Developed persistent message storage using sequential log segments and offset-based indexing for message retrieval. Implemented a client-broker binary protocol with request/response communication and broker discovery for producer and consumer clients.

| Layer | Technology |
|---|---|
| Language | Java |
| Build Tool | Maven |
| Coordination | Apache ZooKeeper |
| Domain | Distributed Systems / Messaging |
| Protocol | Custom binary client-broker protocol |
